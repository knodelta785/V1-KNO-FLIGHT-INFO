# FlightRadar KNO v1.2 — developed by Ongarand
Info kedatangan & keberangkatan Bandara Kualanamu (KNO) saja. Sumber data: Flightradar24.

Fitur: tanggal + logo maskapai, internasional/semua, muat flight sebelumnya, delay merah (hanya yang belum
terbang / sedang terbang), tab Live (peta + playback jejak), widget Kedatangan & Keberangkatan,
jadwal shift untuk widget, tema terang/gelap + warna custom.

Build: push ke GitHub -> tab Actions -> "Build APK" -> unduh artifact `FlightRadarKNO-debug` (APK).

Catatan: papan jadwal, posisi live, dan jejak memakai endpoint Flightradar24 yang tidak resmi
(tidak ada API publik gratis untuk itu). Peta memakai tile OpenStreetMap. Untuk rilis publik,
gunakan lisensi/API resmi.
